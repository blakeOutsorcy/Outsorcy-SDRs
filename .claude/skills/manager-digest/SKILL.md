# Manager digest

Managers only (Blake or Travis). Read only, except coaching lines the manager asks to write. Window: since the last Prishtina working day's 19:00, unless the manager names one.

## Per intern, one row

Dials, connects, conversations (120 s+), voicemails, meetings, Leads enrolled, claims waiting, overdue calls now, live Leads in cadence, last 19:00 scorecard logged yes or no.

## Flags (list each with the Lead or call)

  - Overdue above 20, or live Leads above 45.
  - DNC dialed, or a "Do not call" result whose Lead is still in a cadence.
  - Results logged with no Lead Status change; Leads still Not Contacted after 3 or more completed calls.
  - Clusters of 1 to 5 second No answer results in the same minute.
  - Claims not enrolled 2 days after the split; Zoho companies owned by an intern but missing from accounts/claims.md; the same company held by two people.
  - Calls owned by a manager on an intern's Lead (cadence ownership bug).
  - Anything booked: name, company, date, and whether the handoff Note is there.

## Hand back

The table, the flags, and one suggested coaching line per intern in the [keep] / [change] / [tomorrow's focus] shape. Write a coaching line to interns/<name>/coaching.md only if the manager says so. Keep it short enough to read in two minutes before standup.
