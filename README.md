# Outsorcy Intern SDRs

Working repo for Outsorcy's intern SDR program: the playbook, the master account list, and each intern's accounts, daily log, prospect notes and coaching.

New here? Read `claude/intern-guide.md` first. Claude reads `CLAUDE.md` automatically and follows it.

```
CLAUDE.md                 Claude's instructions for this project
claude/                   playbook, intern guide, Zoho dashboard, target lists, week-one plan
accounts/master-list.md   manager-kept seed list and suppression list
interns/<name>/           accounts.md, daily-log.md, prospect-notes.md, coaching.md
project-setup/            original Claude Project settings and memory (reference)
```
